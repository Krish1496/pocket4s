# Sound assets

- `flip.wav` — single card-flip, cut + normalized + de-clicked from
  "shuffle and card flip" by the Freesound community
  (freesound_community-shuffleandcardflip1-40942). ~120ms, 44.1kHz mono.
  Used as the deal/flip effect in sfx.js. All other effects are
  synthesized in-browser (no asset files).
